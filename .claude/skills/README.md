PhoneCast's UI is plain HTML/CSS/vanilla JS in a Tauri (WebView2/Chromium)
window. Where a skill shows React/Framer Motion code, use the CSS / WAAPI /
@starting-style / matchMedia('(prefers-reduced-motion: reduce)')
equivalents instead.

Included: emil-design-eng, animate, review-animations, improve-animations, animation-performance, find-animation-opportunities, animation-vocabulary, apple-design, break-ui.
Left out (not applicable): ask-sonner (React), animate-expo (React Native),
write-swift, mobile-native, pick-ui-library, prototype.
